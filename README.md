# iMotion

Skill modular untuk AI coding agents yang merancang dan mengimplementasikan motion graphics serta animasi langsung dengan kode. Cakupan utamanya motion browser, kinetic typography, explainer, animasi 2D/slapstick, timeline deterministik, integrasi audio, dan render QA.

## Struktur

- `SKILL.md` — instruksi inti, workflow, prinsip wajib, dan router modul.
- `references/beat-sheet.md` — menerjemahkan brief menjadi urutan beat dan timing.
- `references/motion-grammar.md` — aksi, easing, gerak multiskala, kamera, teks, dan transisi.
- `references/slapstick-kinematics.md` — gag fisik, transformasi karakter/material, rig, dan recovery.
- `references/style-system.md` — style brief, hierarki atensi, dan motion yang bukan slideshow.
- `references/implementation-patterns.md` — arsitektur kode, timeline, determinisme, aksesibilitas, dan performa.
- `references/output-profiles.md` — mode browser, loop, frame-based, explainer, dan ekspor.
- `references/sound-design.md` — cue sheet, layer suara, sinkronisasi, dan mix.
- `references/verification.md` — preview, inspeksi frame, debugging, dan QA ekspor.

## Penggunaan

Salin folder ini ke lokasi skills yang dibaca AI coding agent Anda. Agent sebaiknya membaca `SKILL.md` terlebih dahulu, lalu membuka modul pendukung yang relevan. Lokasi instalasi dan mekanisme pemuatan bergantung pada agent.
